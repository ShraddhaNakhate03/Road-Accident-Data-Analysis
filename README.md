# 🚦 Road Accident Data Analysis

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on a road accident dataset to identify patterns and factors affecting road accidents. The analysis helps understand accident severity, vehicle involvement, road conditions, and time-based accident trends.

The goal of this project is to derive **data-driven insights that can help improve road safety and decision-making**.

---

## 📂 Dataset

Dataset used in this project:

**ROAD_ACCIDENT_ANALYSIS.xlsx**

The dataset contains multiple attributes related to road accidents such as:

* Accident Date
* Accident Severity
* Vehicle Type
* Road Surface Condition
* Weather Condition
* Light Condition
* Number of Casualties
* Location

---

## 🎯 Project Objectives

The main objectives of this analysis are:

* Identify the **distribution of accident severity**
* Analyze **accidents based on vehicle types**
* Study **impact of weather and road conditions**
* Identify **time patterns of accidents**
* Understand factors contributing to **higher casualties**
